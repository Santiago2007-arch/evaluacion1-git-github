# Hackatón ADSO 2026 - Evaluación 1 Git y GitHub

## Descripción del proyecto

Este repositorio contiene la solución de la evaluación práctica de Git y GitHub para la ficha 3349882 del programa ADSO del SENA CDITI Dosquebradas.

## Características de la página

La página web presenta información sobre la Hackatón ADSO 2026. Sus principales características son:

- Sección de agenda con actividades y horarios detallados.
- Sección de inscripción con cupos, requisitos y canales de contacto.
- Sección de ubicación con dirección física y mapa de referencia.

## Tecnologías utilizadas

- HTML para la estructura de la página.
- CSS para los estilos y el diseño.
- Git para el control de versiones.
- GitHub para alojar el repositorio.

## Clonación e instalación

Para descargar el proyecto en tu computador, abre una terminal y ejecuta los siguientes comandos:

```bash
git clone https://github.com/TU_USUARIO/evaluacion1-git-github.git
cd evaluacion1-git-github
```

**Nota:** Reemplaza `TU_USUARIO` por tu nombre de usuario de GitHub.
