# Hackatón ADSO 2026 - Evaluación 1 Git y GitHub

## Descripción
Este repositorio contiene el desarrollo de la evaluación práctica de Git y GitHub para la ficha **3349882** del programa **Análisis y Desarrollo de Software (ADSO)** del SENA CDITI Dosquebradas. El proyecto implementa un sitio web interactivo gestionado bajo un flujo profesional de control de versiones, historias de usuario y trazabilidad con issues.

## Características del Sitio
* **Agenda:** Sección con las actividades programadas y sus respectivas horas[cite: 2].
* **Inscripción:** Apartado con información de cupos, requisitos y canales de contacto[cite: 2].
* **Ubicación:** Sección con la dirección física y enlace de referencia al mapa[cite: 2].
